Construir uma aplicação web para uma loja e-commerce de sapatos que consome dados de uma API própria. A aplicação deve ser dividida em duas partes: um servidor back-end que disponibiliza os dados e uma interface front-end estruturada de forma modular.  
- Deverá ser feito em um repositório github e entregue os arquivos após os testes dentro da plataforma AWS.
- Deverá também ser entregue uma print do teste mostrando rodando (pode ser no celular ou no pc).
- O site deverá estar adequado tanto para PC e tanto para Mobile
- O projeto deverá ter um readme no github explicando o processo executado para de fato visualizarmos o API
- O lojista vai querer que você salve informações do sapato como : nome, marca, preço , modelo , cores , quantidade em estoque , tamanhos disponíveis e se está em promoção. Fora a quantidade em estoque, todas as informações deverão estar dispostas no front end.
